# 소프트웨어개발도구및환경실습

2024년 1학기 · C++ · openFrameworks

한 학기 동안 게임을 만들며 주차마다 다른 자료구조와 알고리즘을 적용한 실습입니다.

## [미로 생성과 탐색](maze-generator)

미로를 생성하고 탈출 경로를 찾는 게임입니다.

- **미로 생성** — 엘러 알고리즘. 미로 전체를 메모리에 올리지 않고 한 행씩 처리.
  각 칸에 집합 번호를 부여해 같은 집합이면 벽을 허물지 않아 순환을 방지하고,
  집합마다 아래로 내려가는 통로를 최소 하나 확보해 고립을 막음
- **경로 탐색** — DFS와 BFS를 각각 구현해 비교.
  DFS는 스택으로 한 방향씩 진행하되 최단 경로를 보장하지 않고,
  BFS는 큐로 가까운 칸부터 확장해 도착 시점이 최단 거리
- 지나온 경로와 실제 탐색한 칸을 따로 기록해 되돌아온 자리가 최종 경로에서 제외되도록 처리
- 탐색 과정을 화면에 그려 두 방식의 확장 형태 차이를 시각적으로 확인

## [테트리스](tetris)

- **1주차** — 필드를 2차원 배열로 관리, 블록을 회전 상태별로 정의.
  4×4 영역을 훑으며 벽이나 기존 블록과의 충돌을 판정
- **2주차** — 연결 리스트로 랭킹 시스템 구현. 파일에서 기록을 읽어 점수 순으로 연결하고,
  구간 조회, 이름 검색, 특정 순위 삭제 기능 제공
- **3주차** — 트리 기반 최적 배치 추천. 각 노드에 필드 상태와 누적 점수를 담고
  가능한 회전과 위치를 자식으로 전개해 최고 점수 경로의 첫 수를 도출.
  레벨을 늘릴수록 노드가 지수로 증가하므로, 각 레벨에서 최고 점수 노드만 남기는 가지치기로
  복잡도를 O((R×W)^L)에서 O(R×W×L)로 축소
