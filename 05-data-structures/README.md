# 자료구조

2024년 1학기 · C

기본 자료구조와 알고리즘을 직접 구현하고 성능을 측정한 과제들입니다.

## [문자열 검색](string-matching)

긴 문자열에서 패턴이 나타나는 모든 위치를 찾는 두 알고리즘을 구현해 비교했습니다.
최대 1,000만 자 문자열과 3,000자 패턴을 처리합니다.

- **단순 비교** — 시작 위치를 한 칸씩 옮기며 패턴 전체를 대조
- **KMP** — 패턴 내 접두사와 접미사가 겹치는 최대 길이를 미리 계산해 두고,
  불일치 시 패턴 포인터만 이동시켜 이미 확인한 문자를 다시 보지 않음

패턴이 완전히 일치한 뒤에도 처음으로 돌아가지 않고 실패 함수 값으로 이동시켜,
겹쳐 나타나는 경우까지 빠짐없이 탐지합니다.
입력 생성기로 조건을 바꿔 가며 실행 시간을 측정했습니다.

## [힙 정렬](heap-sort)

최소 힙과 최대 힙을 배열로 구현하고, 대입 횟수를 최소화하도록 작성했습니다.
최대 100만 개 원소를 처리합니다.

## [크루스칼 MST](kruskal-mst)

최소 힙과 서로소 집합을 결합해 최소 신장 트리를 구합니다.
간선 5,000만 개, 정점 1만 개 규모를 처리하며 메모리 제약을 고려해 전역 배열로 관리했습니다.
