# 알고리즘설계와분석

2024년 2학기 · C, C++

같은 문제를 여러 방식으로 풀고 실행 시간을 비교하거나, 고전 알고리즘을 확장하는 과제들입니다.

## [최대 부분 배열 합](max-subarray)

PGM 형식의 회색조 이미지를 읽어 밝기 값에서 평균을 뺀 뒤,
합이 최대인 부분 행렬을 찾는 문제를 세 가지 방법으로 구현했습니다.
평균을 빼야 음수가 생겨 어느 영역이 주변보다 밝은지가 의미를 갖습니다.

1. **누적 합 테이블** — 부분 행렬의 합을 네 값의 가감으로 구할 수 있으나 좌표를 모두 훑어 O(n⁴)
2. **분할정복** — 열 범위를 고정하고 행 방향으로 압축해 1차원 문제로 변환, O(n³ log n)
3. **카데인** — 같은 압축에 한 번의 순회를 적용, O(n³)

세 방법 모두 합뿐 아니라 시작과 끝 좌표까지 반환하도록 구현했습니다.

## [동적 계획법](dp-problems)

다각형 삼각분할과 회문 복원 두 문제를 DP로 해결했습니다.
최적값 테이블과 별도로 경로 테이블을 두어 해 자체를 복원할 수 있도록 했습니다.

## [정렬 비교](sorting)

레코드 구조체를 대상으로 힙 정렬을 구현해 삽입 정렬과 비교했습니다.
정수가 아니라 구조체이므로 한 번의 교환에 드는 복사 비용이 크다는 점을 고려해,
원소를 맞바꾸는 대신 임시 변수에 담아 두고 최종 위치가 정해지면 한 번만 대입하도록 했습니다.

## [연결 요소별 MST](mst-components)

크루스칼 알고리즘을 확장해, 그래프가 여러 연결 요소로 나뉜 경우 각 요소의 MST를 개별 산출합니다.
서로소 집합에 랭크뿐 아니라 정점 수와 누적 비용을 함께 저장하고, 고립 정점도 처리하도록 했습니다.
