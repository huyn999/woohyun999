# 기초인공지능

2025년 2학기 · Python · PyTorch, scikit-learn

이미지 분류와 표 형태 데이터 분석을 각각 다룬 두 과제입니다.

## [이미지 분류 CNN](pokemon-cnn)

포켓몬 사진을 종류별로 구분하는 CNN을 PyTorch로 직접 설계했습니다.

**구조**
- 합성곱층 4개, 채널을 3 → 32 → 64 → 128로 확장
- 앞의 세 층 뒤에만 풀링을 두어 64×64 입력을 8×8까지 축소
- 마지막 층은 풀링 없이 필터만 한 번 더 적용

**과적합 대응**
사진 수가 적어 학습 정확도만 오르고 검증 정확도가 따라오지 않았습니다.
배치 정규화와 드롭아웃을 넣었으나 비율을 모든 층에 0.3으로 동일하게 주자 성능이 오히려 하락했고,
파라미터가 훨씬 많은 완전연결층에서 과적합이 집중된다고 보아 합성곱 구간만 0.15로 낮추자 회복됐습니다.

**평가**
데이터가 학습용과 검증용으로 나뉘어 있지 않아 분할에 따라 결과가 흔들렸으므로,
5겹 교차검증으로 다섯 번 학습해 평균을 산출했습니다.

**결과** 평균 정확도 96.53%, macro F1 96.51%

## [분류·회귀 모델](tabular-models)

두 개의 문제를 다뤘습니다. 지정된 모델 외에 자체 모델을 별도로 구성해야 했습니다.

### 당뇨병 발병 분류

여덟 개 의료 지표로 발병 여부를 예측하는 문제로, 모델은 지정되어 있고 전처리를 직접 설계했습니다.

- 혈압과 포도당 농도, 피부 두께에 0이 존재. 임신 횟수라면 0이 정상이지만 혈압이 0인 사람은 없으므로
  측정 누락으로 판정하고 중앙값으로 대체
- 사분위 범위를 벗어난 값을 제거한 뒤에도 극단값이 남아, 평균 대신 중앙값을 기준으로 하는 정규화 선택
- 발병군이 적어 다수 클래스로만 답해도 정확도가 높게 나오는 문제가 있어 소수 클래스 오버샘플링

**결과** 지정 모델 5종이 0.6863~0.8105, 전처리 적용 구성이 0.8170

### 월별 자살사망자수 회귀

보건·경제·인구 지표 30개로 예측하는 문제입니다.

- 지표가 단독으로 움직일 때보다 여럿이 맞물릴 때 값이 크게 변동한다고 보아
  두 지표를 곱한 상호작용 항을 모두 생성
- 항이 늘어난 만큼 과적합 위험이 커져 계수에 벌점을 주는 회귀를 병행
- 예측값 분포가 한쪽으로 치우쳐 로그 변환 후 학습, 결과를 역변환
- 선형 모델은 전체 추세를, 트리 계열은 구간별 급변을 잡아내므로
  성질이 다른 세 모델의 예측을 다시 선형 모델로 묶는 스태킹 구성

**결과** RMSE 39.59. 지정 모델 중 최고였던 61.67 대비 36% 개선
